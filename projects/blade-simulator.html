Input file format

One table, one row per blade station. Settings go in the first data row, and exciters and clamps take one row each. This is the same layout as the Excel input files of the original MATLAB tool. The easiest start is to download the generic blade above and replace the numbers. Excel files (.xlsx) can be opened directly. Column names are matched loosely, so spacing and capital letters don't matter.

How it works

The blade is modelled as an Euler-Bernoulli beam, clamped at the root, with 40 finite elements. Stiffness, mass and damping vary along the span as given in the input. The simulator finds the first three natural modes. It then simulates each mode as a mass-spring-damper, and adds the remaining modes as a static correction, so the gravity sag is exact. The load follows a test sequence: gravity ramps in over 5 s (flapwise only). From 10 s (flapwise) or 0 s (edgewise), the exciter force ramps up over 10 s and then runs as a steady sine.

This is a re-write of my MATLAB simulator. It used an explicit finite-difference scheme that needed a time step of 0.00001 s to stay stable. The modal method needs a few thousand steps for a whole test, so it runs in a fraction of a second.

Assumptions: small deflections, bending in one plane only (no flap-edge coupling or torsion), linear damping proportional to mass. Clamps are point masses.

Generic blade: the public NREL 5 MW reference blade (61.5 m), from J. Jonkman et al., Definition of a 5-MW Reference Wind Turbine for Offshore System Development, NREL/TP-500-38060, 2009. Data from the OpenFAST r-test repository (Apache 2.0). Clamps, exciter and damping are my own example values.
